# 🚀 Codyssey — A Logic Quest

> Plataforma gamificada de exercícios de Python com temática espacial, desenvolvida como projeto acadêmico.

---

## 📖 Sobre o Projeto

Codyssey é uma plataforma web educacional que ensina lógica de programação em Python através de uma narrativa espacial imersiva. O aluno assume o papel de um explorador intergaláctico e avança por desafios de código para progredir na missão.

A plataforma foi desenvolvida com foco em engajamento e aprendizado ativo, onde cada exercício é contextualizado dentro de uma história e fornece feedback imediato sobre o código submetido.

---

## ✨ Funcionalidades

- Autenticação de usuários com cadastro e login
- 12 desafios divididos em 3 módulos temáticos: Condicionais, Laços de Repetição e Funções
- Editor de código Python integrado no navegador
- Execução real do código do aluno com retorno de output
- Correção automática comparando o output com o resultado esperado
- Sistema de XP e progresso por desafio
- Interface responsiva com design espacial

---

## 🗂️ Módulos e Desafios

| Módulo | Tema | Desafios |
|---|---|---|
| 1 | Condicionais | 5 desafios |

## 🛠️ Tecnologias Utilizadas

### Frontend
- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase (autenticação e banco de dados)

### Backend
- Python
- FastAPI
- Uvicorn

### Infraestrutura
- Vercel (deploy do frontend)
- Render (deploy do backend)
- Supabase (banco de dados PostgreSQL na nuvem)
